## What is PySpark?

**PySpark** is the Python API for **Apache Spark**, an open-source distributed computing framework designed for processing large-scale data efficiently.

PySpark allows you to:
- Process large datasets in parallel
- Work with structured and unstructured data
- Perform transformations using DataFrames and Spark SQL
- Build scalable data pipelines for analytics and data engineering

Spark handles distributed execution, memory management, and fault tolerance, while PySpark provides a Python-friendly interface to interact with it.
